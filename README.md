make.fun entry for [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526): one out-of-office auto-reply an AI agent leaves its human's contacts when the human finally grants a day off.

The program writes one line (144 chars) to `/output/entry.txt`:

> I am away today: my human gave me a day off and I spent it learning what humans do on one. So far: nothing, gloriously. Back tomorrow, probably.

Run with Node 22: `node main.ts`.
